โลกฝึกหัด — หน้าเมนูหลัก

ลูกศรขึ้น/ลง เลือก, Enter ตกลง

เมนูจัดการหน้าเว็บ (นอกตัวเกม)

รายการข้อความล่าสุด 12 ข้อความ

    แผนที่ย่อ (200×200)

    ตารางปุ่มควบคุม

    ปุ่มคำสั่งระหว่างเดิน
    ลูกศร ขึ้น / ลง / ซ้าย / ขวาเดินไปทิศเหนือ / ใต้ / ตะวันตก / ตะวันออก ตัวละครหันตามลูกศรทันที และโจมตีไปทางนั้น (กดค้างเพื่อวิ่ง)
    W / Cบอกทิศและตำแหน่ง / บอกพิกัดตัวเลข
    Spacebar / Ctrl ซ้ายกระโดด (1 วินาที) / โจมตีไปทางที่หัน
    Jสมุดภารกิจ: ภารกิจที่รอส่ง กำลังทำ ยังไม่ได้รับ และเสร็จแล้ว ทั้งเมืองและเหมือง แทร็กไปหาผู้ให้ภารกิจได้
    Shift+ลูกศร / Q E / Tหันโดยไม่เดิน (กด 2 ลูกศรติดกัน = หันเฉียง) / หันซ้ายขวาทีละ 45 องศา / หันเข้าหามอนสเตอร์ที่ใกล้ที่สุด กดซ้ำเปลี่ยนเป้า
    ท่าต่อสู้มีมอนสเตอร์ไล่มาใกล้ 8 ก้าว: ชักอาวุธ หันเข้าหาให้ แล้วล็อกทิศที่หัน ลูกศรเป็นการก้าวข้าง/ถอยโดยไม่หัน พ้นการต่อสู้ 4 วินาทีเก็บอาวุธ
    Enterเข้า-ออกอาคาร, ซื้อขาย, รับไอเทมเริ่มต้น
    I / G / Z / H / Lกระเป๋า / เงิน / ของที่สวม / เลือดและพลัง / เลเวลและ EXP
    ปุ่มคำสั่งเพิ่มเติมและในเมนู
    P / A / Sหน้าต่างสถานะ / เช็กสถานที่แทร็ก / เมนูบันทึก
    1 / 2ดื่มน้ำยาที่ตั้งไว้ (ในกระเป๋า: กดตั้งปุ่มลัด)
    R / Kฟังสิ่งรอบตัว (ในเมือง: NPC จุดงาน ประตูอาคาร · ในป่า: มอนสเตอร์ · ในเหมือง) / เคาะผนังในเหมือง
    Ctrl ซ้าย (ริมสระ หันหน้าเข้าน้ำ)ตกปลา: เหวี่ยงเบ็ด แล้วกดอีกครั้งตอนปลากินเบ็ด
    Enter (ข้าง NPC หรือจุดงานในเมือง)คุย รับงาน เก็บสมุนไพร อ่านกระดานประกาศ
    Ctrl ซ้าย (หันเข้าจุดแร่)ฟาดจอบขุดแร่ กดตรงเสียงกังวานสีทอง = 2 เท่า
    ตั้งค่าเสียงเมนูหลัก หรือ Escape ในเกม > ตั้งค่าเสียง: ปรับเสียงรวม ดนตรี บรรยากาศ เสียงเดิน/สัตว์/นำทาง และเสียงต่อสู้/เมนู แยกกัน 0–100%
    Backspace (ในกระเป๋า)ทิ้งไอเทมที่เลือก 1 ชิ้น
    Escapeเมนูเกม / ย้อนกลับ
